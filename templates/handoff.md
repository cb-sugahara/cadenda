# Issue引継ぎ（Phase 1 手動版）

- Project / Issue:
- 生成日時 / 元Issue取得日時:
- ソース参照 / 内容ハッシュ:
- 作業worktree / branch / commit:

## 要件と受け入れ条件

元Issueへの参照を付ける。

## 人間が承認した現在の決定

決定ID・投稿者・承認時刻・置き換えた仕様を記載。通常コメントやAI提案と区別する。
承認がなければ「承認待ち」とする。

## 現在の状態

実際の差分・コミット・独立テスト・停止理由を記載。実装者の自己申告だけで成功としない。

## 禁止事項・制約

許可されたworktree外の編集、本番操作、秘密情報の読み取り、未承認仕様の採用は禁止。

## 未解決と次の作業

確認済み・未検証・ブロックを区別する。

## 証跡

BeadsコメントID、コマンド、終了コード、stdout/stderr、テスト、Git差分への参照。
